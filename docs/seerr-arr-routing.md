# Seerr: серверы Radarr и Sonarr по умолчанию

## Требуемая конфигурация MINI-Ubuntu

В Seerr все четыре используемых экземпляра Arr должны быть отмечены как серверы по умолчанию:

| Сервис | Экземпляр | Порт | Признак 4K | Отметка в Seerr |
|---|---|---:|---|---|
| Radarr | Обычный / 1080p | `7878` | Выключен | **Default Server** |
| Radarr | 4K | `7879` | Включен | **Default 4K Server** |
| Sonarr | Обычный / 1080p | `8989` | Выключен | **Default Server** |
| Sonarr | 4K | `8988` | Включен | **Default 4K Server** |

Настройка выполняется отдельно для Radarr и Sonarr. Для каждого типа Seerr допускает один обычный сервер по умолчанию и один 4K-сервер по умолчанию. Поэтому одновременно должны быть назначены четыре отметки: по две на странице Radarr и Sonarr.

При сохранении другого сервера как Default в той же категории Seerr снимает эту отметку с прежнего сервера этой категории. Обычная и 4K-категории независимы: назначение 4K-сервера не отменяет назначение обычного сервера.

## Что делает отметка Default

Seerr использует сервер по умолчанию как целевой экземпляр для одобренной заявки соответствующего типа и качества:

- обычная заявка фильма направляется в обычный Radarr;
- заявка фильма с признаком 4K направляется в Radarr 4K;
- обычная заявка сериала направляется в обычный Sonarr;
- заявка сериала с признаком 4K направляется в Sonarr 4K.

Если для нужной категории не назначен сервер по умолчанию, Seerr не сможет штатно обработать такую заявку.

## Важное различие: Default не означает отправку во все экземпляры

Отметка Default **не включает дублирование одной заявки во все экземпляры**. Она выбирает единственный целевой сервер для заявки с конкретным признаком качества.

Обычная заявка и 4K-заявка в Seerr — отдельные заявки с разными значениями признака 4K. Чтобы получить обе версии фильма или сериала, необходимо создать обычную и 4K-заявки отдельно; обе должны пройти одобрение (автоматическое или ручное). После одобрения каждая направляется в свой экземпляр Arr.

## Проверка

Откройте **Settings → Services** в Seerr и проверьте:

1. В разделе Radarr: обычный экземпляр (`7878`) отмечен как **Default Server**, Radarr 4K (`7879`) — как **Default 4K Server**.
2. В разделе Sonarr: обычный экземпляр (`8989`) отмечен как **Default Server**, Sonarr 4K (`8988`) — как **Default 4K Server**.
3. Для запроса двух вариантов в списке Seerr существуют две отдельные заявки: обычная и 4K; обе имеют статус Approved/Processing либо завершенный статус.

Если одна из одобренных заявок не появляется в соответствующем Arr, проверьте журнал Seerr на предупреждения об отсутствии default Radarr/Sonarr для обычного или 4K-режима.

## Примечание

Порты соответствуют конфигурации MINI-Ubuntu: Radarr 1080p `7878`, Radarr 4K `7879`, Sonarr 1080p `8989`, Sonarr 4K `8988`. Это описание целевой конфигурации Seerr, а не экспорт фактических настроек или секретов. API-ключи и резервные копии конфигурации Arr в репозиторий не помещаются.
